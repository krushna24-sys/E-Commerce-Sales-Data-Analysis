# E-Commerce Sales Data Analysis

## Project Overview
This project focuses on analyzing E-Commerce Sales Data
using Python and Machine Learning techniques.

## Student Information
- Name: Krushna Renurao Markad
- Subject: Fundamentals of Machine Learning
- Department: Electronics & Telecommunication Engineering
- College: Suryodaya College of Engineering & Technology

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Objectives
1. Analyze E-Commerce Sales Data.
2. Perform Data Cleaning and Preprocessing.
3. Visualize Monthly and Product-Wise Sales.
4. Implement Linear Regression.
5. Predict Future Sales.
6. Evaluate Machine Learning Model Performance.

## Machine Learning Algorithm
Linear Regression

## Dataset
The project uses 1000 synthetic sales records
generated using Python.

## Project Features
- Data Preprocessing
- Exploratory Data Analysis
- Sales Visualization
- Model Training and Testing
- Actual vs Predicted Sales
- Future Sales Prediction

## Conclusion
This project demonstrates the application of
Machine Learning in E-Commerce Sales Analysis
and Sales Prediction.

The predictions are for educational demonstration
and are not validated business forecasts.
